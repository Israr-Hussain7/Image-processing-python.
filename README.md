# Image Processing Fundamentals Using Python

## About This Project

This is a small project I created to learn and practice the basics of digital image processing using Python. I used a dog image to explore how images can be loaded, displayed, resized, and converted from color to grayscale.

While working on this project, I learned how different Python libraries can be used to handle images and perform basic processing operations.

## Technologies and Libraries

- Python
- NumPy
- OpenCV
- Pillow (PIL)
- Matplotlib
- Google Colab

## What I Worked On

In this project, I practiced a few basic image processing tasks:

1. Loading and displaying an image using Python.
2. Checking image dimensions and pixel information.
3. Resizing an image using Pillow.
4. Converting a color image into grayscale using OpenCV.
5. Displaying and comparing the original and processed images.

## Project Files

- image_processing_fundamentals.ipynb – The Jupyter Notebook containing the Python code and processing steps.
- dog_image.jpg` – The original dog image used in the project.
- dog_grayscale.jpg` – The grayscale image produced after processing.

## How to Run the Project

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the original dog image if requested by the notebook.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells one by one to see the results.

## What I Learned

Through this project, I gained practical experience with image handling in Python and understood how basic image processing operations work. It also helped me become more familiar with libraries such as OpenCV, NumPy, and Pillow.
